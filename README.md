# 護牙日課

跟著動畫一區一區刷牙，完成後累積連續天數、徽章和夥伴。

護牙日課是一個手機優先的網頁 App（PWA），不需要安裝任何套件，也不需要帳號，打開網頁就能用，也可以加到手機主畫面當成 App 使用。

## 功能

- **刷牙引導**：按開始後先倒數 3 秒。兩顆牙一區、每次往後移一顆（1-2、2-3、3-4…），畫面上會標出現在要刷的區域，每一區停留固定秒數後自動換下一區，也可以暫停、回上一區或跳下一區。
- **鏡像牙齒圖**：所有牙齒圖都跟照鏡子看到的一樣，你的右邊在畫面右邊。
- **牙線與牙間刷**：牙線一個畫面看完整排，照提示先上排、再下排，都從左到右；附教學動畫，可以選擇放在早上或晚上的刷牙流程裡。
- **YouTube 音樂**：可以在設定裡打開並貼上 YouTube 連結，按開始時會同時開啟，回到 App 後再倒數 3 秒開始。
- **固定式維持器**：可設定上、下顎鐵絲從哪一顆牙到哪一顆牙（預設犬齒到犬齒），刷牙時會加入鐵絲周圍的清潔步驟。
- **早晚兩次紀錄**：首頁可切換早上／晚上，完成後記錄在當天。
- **紀錄頁**：月曆檢視每天的完成情況、連續天數與徽章。
- **夥伴**：完成刷牙、牙線、牙間刷可以得到清潔點數，點數可以換新夥伴。
- **設定**：每一區停留秒數、YouTube 音樂連結、提示音、震動、清除所有紀錄。
- **離線可用**：透過 Service Worker 快取，沒有網路也能開啟。
- **深色模式**：跟著系統設定自動切換。

## 檔案結構

```
index.html             整個 App（HTML、CSS、JavaScript 都在這一個檔案）
manifest.webmanifest   PWA 設定（名稱、圖示、主題色）
sw.js                  Service Worker，負責離線快取
icons/                 App 圖示
```

## 在本機執行

Service Worker 需要透過 `http://` 或 `https://` 開啟才會啟用，所以請用任一個靜態伺服器，例如：

```bash
python3 -m http.server 8000
```

再用瀏覽器打開 <http://localhost:8000>。

直接雙擊 `index.html` 也能使用，只是不會有離線快取和「加到主畫面」功能。

## 部署

整個專案是純靜態檔案，可以直接放到 GitHub Pages 或任何靜態網站空間。

修改 `index.html` 或圖示後，記得把 `sw.js` 裡的 `VERSION` 改成新的值（例如 `huya-v3`），已經安裝的使用者才會拿到新版本。

## 資料儲存

所有紀錄都存在瀏覽器的 `localStorage`，只存在這台裝置上，不會上傳到任何伺服器。清除瀏覽器資料或在設定頁按「清除所有紀錄」都會把紀錄刪掉。
